Unwritten Studio portable mode

While this file sits next to effectcraft.exe, Unwritten Studio keeps its settings, keyboard shortcuts,
crash-recovery files, logs and plug-ins in the Unwritten StudioData folder beside it instead of
%APPDATA%\Unwritten Studio. Copy the whole folder to move Unwritten Studio with its settings.

The disk cache, media cache and conformed audio still go to %LOCALAPPDATA%\Unwritten Studio unless
you choose other folders in Edit > Preferences > Disk.

Delete this file to use the normal per-user settings folder (%APPDATA%\Unwritten Studio) instead.
If Unwritten StudioData can't be written (for example on a read-only drive), Unwritten Studio logs a
warning and uses %APPDATA%\Unwritten Studio instead.
